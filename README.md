# Philotas Site

The philotas.com marketing site. Static HTML; every page is a real file (no
SPA router). Deployed to the nginx root behind Cloudflare via the
site-deploy workflow. Copy rules: no pricing figures without sign-off, the
third-party data attribution paragraphs must stay verbatim, and the 31
region deep links in index.html are load-bearing (never delete or alter).
