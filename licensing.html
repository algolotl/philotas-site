Licensing

What the licences grant

The code is Apache-2.0. A support license adds the services a production deployment needs.

Apache-2.0

The Philotas core is licensed under the Apache License 2.0. That grants you the right to use, modify and distribute the code, including commercially, and includes a patent grant. The licence requires you to keep the copyright and licence notices and to state changes you make. It provides the software as-is, without warranty.

You can run Philotas on your own hardware, change it, and redistribute your changes under the same licence. You do not need to buy anything to do this.

What the support license adds

The Apache licence covers the code. The support license is a separate commercial agreement for organisations running Philotas in production. Support licences are sold by Kovacorp Pty Ltd, the Philotas maintainer.

Support SLA
  • Named contacts and agreed response times.
  • A path for incidents and questions.
Upgrade assurance
  • Guidance and support across releases.
  • Compatibility notes before you upgrade.
Enterprise add-ons
  • Air-gapped packaging.
  • Accreditation support.
  • Licensed-feed enablement.
  • Implementation.

The support license does not take away what the Apache licence already grants. See pricing for the tiers.

Trademarks

Philotas is a trademark of Kovacorp Pty Ltd. The Apache licence grants rights in the code, not in the names or marks. If you distribute a modified version, name it something else so that Philotas continues to refer to the original project.
